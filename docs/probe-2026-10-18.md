**Run:** https://github.com/lauraevan/LauncherRE/actions/runs/39159128732

**Target:** Mojang Linux launcher core 3.41.29, official pinned distribution manifest. The GitHub Actions research runner retrieved and SHA-1 verified seven official files in a throwaway checkout.
